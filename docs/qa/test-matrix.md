# QA automation matrix

Layers: **Vitest unit** (domain logic, contracts; `npm test`), **Supabase integration and security** (RLS, SQL functions, real Auth and Storage; `npm run test:integration`), **pgTAP** (schema-level guarantees; `npm run test:db`), **Playwright** (critical journeys at 5 viewports, axe accessibility; `npm run test:e2e`, smoke subset `npm run test:e2e:smoke`), **performance budgets** (`npm run test:perf`).

Cross-cutting:

- **Accessibility:** `accessibility.spec.ts`, plus an axe pass inside the transactions, calendar, portals and payments specs (desktop and 390 px phone); `keyboard-a11y.spec.ts` (keyboard-only login, dialog focus trap and return, WCAG 2.5.8 target size).
- **Responsive and navigation:** `responsive.spec.ts`, `navigation.spec.ts` at 375, 390 and 430 px, tablet and desktop.
- **PWA:** `pwa.spec.ts` (manifest, icons, service worker; offline fallback; caches contain no private pages).
- **Performance:** `tests/performance/mobile-budgets.spec.ts` (4× CPU, 150 ms RTT, 1.6 Mbps).
